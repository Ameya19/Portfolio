ExpenseSplitter

ExpenseSplitter is a full-stack web application that simplifies splitting shared expenses among groups of people. Built with ASP.NET Core 9 Web API (Clean Architecture) and Angular 17 (Standalone Components), it features JWT authentication, real-time balance calculation using a greedy debt-simplification algorithm, and a complete expense management system with multiple split types (Equal, Percentage, Exact). The backend uses PostgreSQL with Entity Framework Core for data persistence, while the frontend leverages Angular Material for a clean, responsive UI.
