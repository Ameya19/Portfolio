Concept Map Generation and Summarization

Built an intelligent document analysis application that automates concept map generation and content summarization using Natural Language Processing and machine learning techniques. The system extracts important concepts, maps semantic relationships, and produces concise summaries to improve knowledge discovery and information retention.

ExpenseSplitter

ExpenseSplitter is a full-stack web application that simplifies splitting shared expenses among groups of people. Built with ASP.NET Core 9 Web API (Clean Architecture) and Angular 17 (Standalone Components), it features JWT authentication, real-time balance calculation using a greedy debt-simplification algorithm, and a complete expense management system with multiple split types (Equal, Percentage, Exact).

Modernized Pokedex

An ultra-fast, tactical national Pokédex terminal. Explore all 1,025 Pokémon with live cries, dynamic type damage matrices, multi-branch evolution paths, physical height scales, and squad team analyzers.
